# AI Student Performance Analytics System

An interactive web application built with Python and Streamlit that analyzes student academic performance using data science and machine learning techniques.

## Features

- **Dashboard** — Class-wide overview with average scores, top students leaderboard, and subject-wise performance bar chart
- **Student Analysis** — Individual student deep-dive with radar chart, attendance trends, predicted marks, and risk badge
- **At-Risk Detection** — Automatic classification of students into Critical, At Risk, and Safe tiers with donut chart and colour-coded table
- **AI Insights** — Personalized improvement suggestions for each student based on their marks and attendance


## How It Works

Upload a CSV or Excel file containing student marks and attendance data. The system automatically detects subjects, calculates performance scores, runs a machine learning model, and classifies every student by risk level.
